# 12. 분야 카테고리와 적응 규칙

## 1. 왜 필요한가

6단계 구조는 분야와 무관하게 고정이다. 하지만 **각 단계가 무엇으로 채워지는지는 분야마다 다르다.**

가장 두드러진 자리가 6번 본론의 **예시**다.

| 분야 | 예시의 자연스러운 형태 |
|---|---|
| 컴퓨터 | 코드 |
| 수학 | 계산 과정 |
| 과학 | 실험 장면 |
| 미술 | 보정 전 / 후 비교 |
| 운동·요리 | 동작 순서 |

이걸 전부 "코드"로 취급하면 수학 학습지에 `<pre><code>` 로 미분 계산이 들어간다. 어색하다.

## 2. 12개 카테고리

| # | 카테고리 | 예시 주제 | 예시 형태 | 필기 여백 |
|---|---|---|---|---|
| 1 | **수학** | 미적분, 선형대수, 확률 | 계산 과정 | 크게 (직접 풀어야 함) |
| 2 | **물리·화학** | 양자역학, 이중슬릿, 열역학 | 실험 장면 | 보통 (그림 그림) |

| 4 | **미술·디자인** | 색보정, 구도, 타이포 | 전/후 비교 | 크게 (스케치) |

## 3. `example.kind` — 예시의 다섯 가지 모양

스키마가 `code` 하나만 갖고 있으면 12개 카테고리 중 1개만 자연스럽다. 그래서 종류를 나눈다.

| kind | 쓰는 곳 | 렌더 |
|---|---|---|
| `code` | 컴퓨터 | 등폭 글꼴 블록, 언어 표시 |
| `calc` | 수학, 경제 | 등폭 + 줄마다 정렬. 계산 한 줄씩 |
| `steps` | 운동, 요리, 음악, 업무 | 번호 매긴 목록 |
| `compare` | 미술, 언어 | 좌/우 대비. `before` `|` `after` 로 구분 |
| `scene` | 과학, 역사, 심리 | 인용 블록. 장면 묘사 |

`language` 는 `kind: 'code'` 일 때만 쓴다. 다른 종류에 넣으면 검증기가 거부한다.

## 4. 분야별 목소리 조정

파르의 성격은 그대로다. 다만 **자기 개방의 내용**이 분야를 탄다.

| 분야 | 파르가 헤맸던 지점의 예 |
|---|---|
| 수학 | "저는 극한 기호를 볼 때마다 눈이 미끄러졌어요" |
| 물리 | "관측하면 달라진다는 말이 처음엔 미신처럼 들렸어요" |
| 미술 | "커브를 만지면 항상 사진이 이상해져서 한동안 안 썼어요" |
| 컴퓨터 | "그래서 잔액은 어디에 저장하냐부터 막혔어요" |

## 5. 분야별로 특히 조심할 것

- **수학·물리**: 기호를 설명 없이 쓰지 않는다. `dx` 를 처음 쓰면 "아주 작은 변화량" 이라고 푼다
- **미술·음악**: 감각을 말로 옮겨야 한다. "따뜻하게" 대신 "노란기를 5 정도 올려서"
- **역사**: 연도 나열 금지. 사건 하나를 장면으로
- **심리**: 진단하지 않는다. "당신은 ~한 사람입니다" 금지
- **건강·요리**: 안전 경고가 필요하면 `caution` 콜아웃으로 반드시 넣는다

파르 등장 수 · 예시 종류 적합성 · 렌더 성공 · 어려운 말 밀도.

### 12분야 커버리지 (12/12)

| 분야 | 픽스처 주제 | 이 분야에서 "관찰"을 무엇으로 만들었나 |
|---|---|---|
| 수학 | 미분 — 한 순간의 기울기 | 할선이 접선으로 가는 그래프를 슬라이더로 직접 |
| 물리·화학 | 이중슬릿 — 경로 정보 | 두 분포를 나란히. **정량 슬라이더는 뺐다**(정직한 물리) |
| 컴퓨터 | 이벤트 소싱 | 같은 세 사건을 두 방식으로 적은 표 |
| 미술 | 색보정 | 톤커브·견본. **실물 사진이 없어 출고 보류** |
| 음악 | 종지 | 소리를 못 들려주므로 **네 진행의 반음 움직임 표**로 옮겼다 |
| 언어 | 은/는 vs 이/가 | 조사만 바꾼 **최소쌍 9줄** |
| 경제 | 복리 | 단리·복리 대조표 + 곡선이 직선에서 벌어지는 지점 |
| 역사 | 사료 비판 | 두 사료를 일곱 기준으로. **승자를 발표하지 않는다** |
| 비즈니스 | 손익분기점 | 가격만 바꿔 두 번 센 계산 |
| 건강 | 지연성 근육통 | 젖산과 통증의 **시간표가 어긋나는 것** |
| 요리 | 겉면 굽기 | 저울 숫자 — 지진 쪽이 오히려 더 줄었다 |
| 심리 | 확증 편향 | 확인만 한 사람과 반증을 물어본 사람의 기록 |

**여기서 배운 것.** 6단계(예측 → 관찰)는 관찰할 현상이 없는 분야에서 가장 위태롭다.
음악·언어·역사에서 무너지지 않은 이유는 하나다 — **예측의 질문을 "어느 쪽이 맞나" 에서
"무엇이 그것을 만드나" 로 한 칸 옮기면** 눈으로 확인 가능한 증거가 생긴다.
역사에서는 한 걸음 더 갔다. 관찰의 산출물을 *답*이 아니라 **질문의 재구성**으로 두었다.
