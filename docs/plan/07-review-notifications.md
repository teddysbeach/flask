# 07. 망각곡선 복습 & 로컬 알림

## 1. 컨셉

에빙하우스 망각곡선: 학습 직후부터 기억은 급격히 감소하지만, **잊기 직전에 다시 꺼내면** 곡선이 완만해진다.
Baewoom은 학습지의 **질의 5개**를 재료로, 확장되는 간격에 맞춰 **하루 한 문제씩 로컬 알림**을 보낸다.

> 알림은 "복습하세요"가 아니라 **문제 그 자체**다.
> 알림 배너에서 문제를 읽는 순간 이미 인출(retrieval)이 시작된다. 이게 이 기능의 전부다.

```
알림: "🧠 이벤트 소싱 — 이벤트 스토어에 저장되는 것은 상태인가, 변화인가?"
  → 탭 → 복습 카드 화면 → 답 떠올리기 → [정답 보기] → [모르겠음/어려움/보통/쉬움]
  → 다음 간격 재계산 → 다음 알림 예약
```

## 2. 스케줄 알고리즘

**기본 간격(1회차~5회차): 1일 · 3일 · 7일 · 16일 · 35일** (에빙하우스 기반 확장 간격)

학습지 생성 완료 시점에 문제 5개를 5회차에 1:1로 배정한다 — **회차마다 다른 문제**가 나온다.
같은 문제를 반복하는 것보다 학습지 전체를 훑는 효과가 크다.

| 회차 | 기본 D+ | 배정 문제 |
|---|---|---|
| 1 | +1일 | quiz[0] |
| 2 | +3일 | quiz[1] |
| 3 | +7일 | quiz[2] |
| 4 | +16일 | quiz[3] |
| 5 | +35일 | quiz[4] |

응답 후 다음 간격은 **SM-2 lite** 로 조정한다 (서버 `review-answer` 에서 계산):

```
grade: 0=모르겠음 1=어려움 2=보통 3=쉬움

ease' = clamp(ease + (0.1 - (3 - grade) * (0.08 + (3 - grade) * 0.02)), 1.3, 2.8)

if grade == 0:  # 완전히 잊음 → 짧게 다시
    interval' = 1
    repetition' = max(repetition - 1, 0)
else:
    interval' = round(base_interval[repetition + 1] * (ease' / 2.5))
    repetition' = repetition + 1

due_at' = 다음_알림_시각(now + interval' 일)   # §3 시간대 규칙
if repetition' >= 5 and grade >= 2:  state = 'retired'   # 졸업
```

- 발화 시각은 사용자가 정한 **복습 시간대**(기본 21:00, 로컬 타임존)로 정규화한다.
- 하루에 여러 학습지의 복습이 겹치면 **최대 3개까지만** 알리고 나머지는 다음 날로 밀거나 앱 내 배지로만 표시.
  (알림 피로가 이 기능을 죽이는 1번 원인)
- 미응답 알림은 3일 뒤 1회만 재알림, 그래도 없으면 `state='skipped'` 처리 후 다음 회차로.

## 3. 시간대

- `due_at` 은 UTC `timestamptz` 로 저장한다.
- 로컬 알림 예약은 `timezone` 패키지로 사용자 로컬 시각으로 변환해서 건다.
- 여행/시간대 변경 시 앱 포그라운드 진입마다 전체 재스케줄 → 새 시간대 기준으로 다시 계산.
- 사용자 설정: 복습 시간대(기본 21:00), 방해 금지 구간(기본 23:00~08:00), 알림 On/Off.

## 4. 로컬 알림 구현 — **iOS 64개 한도가 설계를 지배한다**

iOS는 앱당 **예약 대기 중인 로컬 알림을 64개까지만** 유지한다. 초과분은 조용히 버려진다.
학습지 20개 × 5회차 = 100개 알림이면 이미 넘는다. 따라서 "다 걸어두기"는 불가능하다.

**해결: 롤링 재스케줄러**

```dart
// 앱 포그라운드 진입 / 복습 응답 후 / 학습지 생성 완료 후 매번 실행
Future<void> rescheduleAll() async {
  final upcoming = await api.upcomingReviews(limit: 60);   // due_at 오름차순
  await notifications.cancelAll();
  var scheduled = 0;
  for (final r in upcoming) {
    if (scheduled >= 48) break;                 // 64에서 여유 16 확보 (다른 알림용)
    if (r.dueAt.isBefore(now)) continue;
    await notifications.zonedSchedule(
      id: r.stableId,                            // review_id 해시 → 중복 방지
      title: '🧠 ${r.worksheetTitle}',
      body: r.question,                          // 알림 본문 = 문제 그 자체
      scheduledDate: tz.TZDateTime.from(r.dueAt, tz.local),
      payload: jsonEncode({'type': 'review', 'review_id': r.id}),
      androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
    );
    scheduled++;
  }
}
```

| 항목 | 처리 |
|---|---|
| 재스케줄 트리거 | 앱 포그라운드 · 복습 응답 후 · 학습지 생성 완료 후 · 알림 탭 후 |
| 알림 제목 | 학습지 제목 (맥락 제공) |
| 알림 본문 | **문제 원문**. 100자 초과 시 잘라내되 문장 단위로 |
| payload | `{type:'review', review_id}` → go_router 딥링크 `/review/{id}` |
| 권한 | 온보딩이 아니라 **첫 학습지 완성 직후**에 요청 (가치를 보여준 뒤 물어야 승낙률이 높다) |
| Android | `SCHEDULE_EXACT_ALARM` 권한 + Doze 대응 `exactAllowWhileIdle` |
| 알림 없이도 | 홈 화면에 "오늘의 복습 N개" 카드 항상 노출 (알림 거부 사용자 대비) |

**핵심**: 서버의 `review_schedules` 가 소스 오브 트루스이고, 로컬 알림은 **파생된 캐시**다.
로컬 알림이 유실돼도 앱을 열면 복습 큐가 정확히 복원된다.

## 5. 복습 카드 화면 (`/review/{id}`)

```
┌────────────────────────────┐
│ 이벤트 소싱 · 3회차 · D+7   │
├────────────────────────────┤
│ Q. 이벤트 스토어에 저장되는  │
│    것은 상태인가 변화인가?   │
│                            │
│   [ 정답 보기 ]             │   ← 먼저 스스로 떠올리게 (인출 연습)
├────────────────────────────┤
│ (정답 공개 후)              │
│ A. 변화(이벤트)의 시퀀스...  │
│ 해설: ...                   │
│                            │
│ 얼마나 기억났나요?           │
│ [모르겠음][어려움][보통][쉬움]│
├────────────────────────────┤
│ 📄 학습지에서 이 부분 보기   │   ← 뷰어 + scrollToQuiz(quiz_id)
└────────────────────────────┘
```

- 정답을 보기 전에 **반드시 한 번 멈추게** 한다. 바로 정답이 보이면 인출 효과가 사라진다.
- "학습지에서 보기" → 해당 문제 위치로 스크롤 + 그때 쓴 내 필기가 그대로 보인다. 이게 이 앱의 순간이다.
- 오프라인에서도 동작: 복습 큐와 문제·정답을 Drift에 캐시. 응답은 큐잉했다가 온라인 시 서버 전송.

## 6. 지표

| 지표 | 의미 |
|---|---|
| 알림 발화 → 탭률 | 알림 문구(=문제)의 품질 |
| 탭 → 응답 완료율 | 복습 카드 UX |
| 회차별 평균 grade 추이 | 실제 학습 효과. 회차가 올라가며 grade가 오르면 작동하는 것 |
| `retired` 도달률 | 5회차 완주 비율 |
| 알림 끄기 비율 | 알림 피로 경보. 3% 넘으면 §2의 일일 상한을 조인다 |
