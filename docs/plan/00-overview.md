# 00. 제품 개요 — ONPAR (온파)

> **ONPAR** — 온(한국어: 전부의·온전한) + par(라틴어·스페인어·영어: 동등한).
> "모두가 같은 자리에서 배운다."
> 배움에는 원래 자리 차이가 있다 — 좋은 학원, 좋은 선생, 좋은 부모.
> ONPAR는 누가 무엇을 배우든 같은 품질의 학습지를 받는다는 전제를 이름에 담는다.

## 1. 한 줄 정의

> **배우고 싶은 개념을 입력하면, 서버가 11개 섹션으로 구조화된 학습지(HTML)를 만들어주고,
> 아이패드에서 애플펜슬로 바로 필기하며 풀고, 망각곡선 주기에 맞춰 복습 문제를 로컬 알림으로 보내주는 앱.**

## 2. 왜 만드는가 (문제 정의)

| 기존 학습 방식 | 문제 |
|---|---|
| 검색 / 블로그 | 파편적. "왜 이게 생겼는지"가 빠져 있어 맥락 없이 암기하게 됨 |
| 강의 / 영상 | 수동적. 손으로 쓰지 않아 남지 않음 |
| LLM 챗봇 | 대화가 휘발됨. 다시 안 봄. 구조가 없음 |
| 종이 학습지 | 구조는 좋으나 내가 원하는 주제가 없음 |

ONPAR는 이 넷의 교집합을 노린다: **개인화된 주제 + 고정된 좋은 구조 + 손필기 + 강제 복습.**

## 3. 핵심 가설

1. **구조가 콘텐츠보다 중요하다.** LLM에 "설명해줘"라고 하면 매번 다른 모양이 나온다.
   11개 섹션을 고정하면 사용자는 "다음에 뭐가 나올지" 예측하며 읽을 수 있고, 이게 학습 효율을 올린다.
2. **손으로 쓴 것만 남는다.** 읽기 전용 문서는 소비되고 끝난다. 필기 레이어가 있으면 학습지가 "내 것"이 된다.
3. **복습이 없으면 다 잊는다.** 에빙하우스 망각곡선 기반 간격 반복 알림이 앱의 리텐션 엔진이자 학습 효과의 핵심이다.
4. **처음 2개가 전부다.** 무료 2장의 품질이 곧 전환율이다. 여기서 모델·프롬프트에 아끼지 않는다.

## 4. 스코프

### v1 (MVP)에 들어가는 것

- 이메일 / Apple / Google 회원가입·로그인
- 계정당 **학습지 2개 무료 생성** (원자적 쿼터 차감, 실패 시 자동 환불)
- 주제 입력 → 서버에서 학습지 생성 (11섹션 고정 구조, 비동기 잡)
- 정해진 규격의 HTML 학습지 렌더링 (앱 디자인 시스템과 동일한 토큰 사용)
- 아이패드 필기 레이어 (Apple Pencil 필압/기울기, 팜 리젝션, 펜/형광펜/지우개/실행취소)
- 필기 데이터 로컬 저장 + 서버 동기화
- 망각곡선 복습 스케줄 + **로컬 알림**으로 복습 문제 1개씩 전송
- 복습 카드 화면 (문제 → 정답 확인 → 체감 난이도 → 다음 간격 재계산)
- 사전학습 제안 3개 → 탭하면 해당 주제로 새 학습지 생성 플로우 진입
- **인앱결제** — 소모성 상품 「학습지 5장 1,900원」 + 서버 영수증 검증

### v1에 들어가지 않는 것 (명시적 제외)

- 구독 상품 · 번들 할인 · 프로모션 코드 (v1은 5장 단일 상품 하나)
- 학습지 공유 / 공개 갤러리 / 소셜
- 웹 버전 (Flutter Web은 v2)
- 필기 OCR, 자동 채점
- 다국어 (v1은 한국어 콘텐츠 전용)
- 푸시(원격) 알림 — v1은 **로컬 알림만**

## 5. 타깃 & 플랫폼 우선순위

## 7. 유닛 이코노믹스 — 정직한 계산

가격이 정해졌으니(5장 1,900원) 숫자를 맞춰봐야 한다. **현재 구조는 적자다.** 근거를 그대로 적는다.

### 팩 1개당

| 항목 | 30% 수수료 | 15% 수수료 (소규모 사업자) |
|---|---|---|
| 표시가 (VAT 포함) | 1,900원 | 1,900원 |
| VAT 10% 제외 | 1,727원 | 1,727원 |
| 스토어 수수료 차감 후 **실수령** | 1,209원 | **1,468원** |
| 생성 원가 (5장 × 133원) | −665원 | −665원 |
| **팩 순마진** | **544원** | **803원** |

> 장당 원가 133원은 평균치(`$0.095`). 최악 케이스 149원 기준이면 마진이 각각 464원 / 723원으로 내려간다.
> `04-worksheet-spec.md` §4.

### 손익분기 전환율

무료 2장은 매출 0원에 원가만 **266원/가입자**. 이걸 팩 마진으로 덮어야 한다.

| 수수료 | 손익분기 전환율 (가입자당 평균 1팩 가정) |
|---|---|
| 15% | **33.1%** |
| 30% | **48.9%** |

**일반 프리미엄 앱의 유료 전환율은 2~5%다. 33%는 현실적인 숫자가 아니다.**

신규 1,000명 · 전환율 5% · 구매자당 1.5팩 시나리오:
```
무료 2장 원가   1,000명 × 266원   = −266,000원
팩 판매         50명 × 1.5팩 × 803원 = + 60,225원
────────────────────────────────────────────
                                    −205,775원
```

### 그런데 반대편도 봐야 한다

무료 2장 원가 266원은 **사실상 CAC(고객 획득 비용)** 다.
광고로 앱 설치 하나를 얻는 데 보통 수천 원이 든다는 걸 감안하면 **266원은 극단적으로 싼 CAC** 이고,
게다가 "제품을 실제로 써본" 유저를 얻는다. 이건 버려지는 돈이 아니다.

즉 이건 "가격이 틀렸다"가 아니라 **"적자를 어디까지 감내하며 성장할 것인가"** 의 문제다.
자금 계획이 있다면 1,900원은 초기 확산에 유리한 공격적 가격이고, 없다면 아래 레버가 필요하다.

### 레버 3개 (조합 가능)

| # | 레버 | 효과 | 대가 |
|---|---|---|---|
| A | **가격 5장 3,900원** | 팩 마진 803 → 2,349원. 손익분기 **11.3%** | 장당 780원 체감. 진입 저항 상승 |
| B | **무료 2장 → 1장** | 무료 원가 266 → 133원. 손익분기 **16.6%** | "무료 2장이 전환율을 결정한다"는 초기 가설과 정면 충돌 |
| C | **집필 모델 Sonnet 5 → Haiku 4.5** | 장당 원가 133 → 101원. 손익분기 **21%** | 본문 문장 품질 하락. 설계는 Opus라 구조는 유지되지만 문장이 얕아진다 |

### 권고

1. **소규모 사업자 프로그램(수수료 15%)에 무조건 등록한다.** Apple Small Business Program / Google Play —
   연매출 100만 달러 이하면 신청만으로 30% → 15%. 이건 공짜로 마진이 47% 오르는 유일한 레버다.
2. **1,900원으로 베타를 시작하고 전환율을 실측한다.** 위 계산은 전부 가정이다. 실제 전환율이 나오기 전에
   가격을 올리면 확산 기회를 잃는다.
3. **무료 2장 원가를 "마케팅 예산"으로 명시적으로 편성한다.** 월 신규 가입 상한을 예산에서 역산해 걸어둔다
   (`05-api-spec.md` §5 소프트 차단과 같은 장치).
4. 베타 종료 시 전환율이 **10% 미만이면 레버 A**(가격 인상)를, **10~20%면 레버 C**(원가 절감)를 먼저 당긴다.
   레버 B(무료 장수 축소)는 제품 가설을 건드리므로 마지막이다.
